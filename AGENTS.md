## Agent skills

### Issue tracker

GitHub Issues are the source of work items; use `gh` from this clone. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical labels as defined in `docs/agents/triage-labels.md`.

### Domain docs

Single-context: read root `CONTEXT.md` and relevant decisions in `docs/adr/`. See `docs/agents/domain.md`.

### UI and design system

For UI or component work, follow `docs/ui-design-system-guidelines.md`, accepted ADR 0024, and any applicable screen-specific guideline such as `docs/settings-ui-guidelines.md`. Explicit user design requirements take precedence over the general visual system.
